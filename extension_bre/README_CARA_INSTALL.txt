 CARA MENGINSTALL EKSTENSI BRE (BROWSER EXTENSION) MOTION STUDIO AI
====================================================================

1. Ekstrak (Unzip) berkas "Motion_Studio_AI_Extension_BRE.zip" ini ke dalam folder komputer Anda.

2. Buka Browser Google Chrome, Microsoft Edge, atau Brave.

3. Buka halaman Ekstensi Browser:
   - Google Chrome / Brave : Ketik chrome://extensions/ di address bar
   - Microsoft Edge       : Ketik edge://extensions/ di address bar

4. Aktifkan toggle "Mode Pengembang" (Developer Mode) di pojok kanan atas layar.

5. Klik tombol "Muat yang tidak dikemas" (Load unpacked) di pojok kiri atas.

6. Pilih folder tempat Anda mengekstrak berkas ekstensi ini.

7. Selesai! Klik ikon puzzle di pojok kanan atas browser, lalu pin/sematkan "Motion Studio AI - BRE Extension".

8. Masukkan RunningHub API Key Anda dan mulai generate video gerakan animasi!
